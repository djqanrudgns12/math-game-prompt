사용 순서

  1. 게임과 수업 조건을 고르고 프롬프트를 복사하세요.
  2. ChatGPT 새 대화에서 프롬프트를 붙여 넣고 활동지 사진·PDF 1~2개를 첨부하세요.
  3. 완성된 HTML 파일을 받으세요. 코드로 받았다면 전체를 메모장에 붙이고 UTF-8, 모든 파일 형식으로 game.html을 저장하세요.
  4. 파일을 브라우저로 열고 문제 예시와 터치를 확인하세요. 화면을 확장했다면 창을 칠판 쪽으로 옮겨 주세요.

학년·차시가 없어도 문제 내용에서 학습 목표를 파악하도록 요청합니다.
