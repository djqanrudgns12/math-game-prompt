# 프롬프트 진행 안정성 보강 2.0

2026-09-11. 제작 지시문은 영어, 생성 게임의 모든 사용자 문구는 한국어로 지정했다. 기존 생성기의 한국어 화면과 선택 구조는 유지한다.

## 문제와 변경

정답 제출 후 다음 버튼이 작동하지 않거나, 궤도를 먼저 고른 뒤 문제를 풀면 진행하지 못한다는 사용자 보고를 반영했다. 보고된 생성 게임의 실제 HTML은 제공되지 않았으므로 특정 게임의 원인을 확정하거나 수정 완료로 표시하지 않는다.

기존에는 제출 중복 방지 지시가 중심이었지만, 이제 제출 잠금과 다음/재도전/추가 선택 권한을 분리하도록 요구한다. 현재 상태를 기준으로 버튼 표시와 이벤트 처리가 동일한 허용 조건을 사용하고, 필요한 마지막 조건이 어느 행동에서 충족되든 공통 판정 경로가 실행되게 한다. 추가 선택이 답안 자체인지, 별도 전략인지, 순서가 필요한 조작인지 먼저 구분한다.

| 범위 | 새 필수 지시 |
|---|---|
| 역순 선택 | 답→궤도와 궤도→답 모두 처리, 선택 보존, ID 0 허용, 권한 1회 소비 |
| 다음 버튼 | 정답 제출 잠금과 다음 권한 분리, 매 상태 변화 후 허용 조건 재계산, 이유 없는 무반응 금지 |
| 오답·재도전 | 오답 후 성공 전용 행동 우회, 1.2초 잠금 만료 갱신, 같은 원문항의 도움·무보상 기록 유지 |
| 화면 갱신 | 재렌더 후 이벤트 유실·중복 등록 방지, 다른 학생의 DOM·포인터 보존 |
| 연출 실패 | 애니메이션·효과음 완료와 실제 진행 분리, 무음·움직임 감소에서도 동일한 논리 결과 |
| 공통 라운드 | 참가자 집합 고정, 제출·풀이 확인 대기 한도, 무제한에서도 교착 방지 |
| 자원·보드 | 중복 소비·음수 재고 방지, 목표 소멸 시 권한 보존, 빈 선택지·막힌 경로·마지막 문제 처리 |
| 시간·재시작 | 단조 증가 시계, 실제 마감 검사, 남은 잠금 보존, 과거 판/문항의 입력·콜백 거부 |
| 수학 | 원시 조건 독립 검산, 동치·복수 해·경계·안전 정수·생성 상한·검증된 예비 문제 |
| 진단 | 실제 함수로 격리 상태 점검, 고정 난수·가상 시계, 미실행 구분, 실패·복구 경로 |

22개 공통 섹션, 입력 순서 추적 6개, 회귀 사례 17개를 출력한다. 20개 장르와 새 게임 구상 각각에 행동·진행·종료·소진·복구·장르별 테스트를 추가했다. 12개 분위기의 영문 지시는 기존 미리보기와 팔레트·장면 구성을 맞춘다. 선택하지 않은 장르 계약은 출력하지 않는다.

## 편집·빌드 경로

- `prototypes/prompt-en.txt`: 현재 영문 본문 단일 원본.
- `prototypes/prompt-contracts.js`: 선택 장르·테마의 영문 계약.
- `prototypes/compiler.js`: 정규화된 설정과 한국어 교사 입력을 보존하는 영문 조립기.
- `scripts/build-prototypes.cjs`: 카탈로그, `prompt-base.txt`, 예시와 배포 HTML 생성.
- `docs/prompt-contract-draft.md`: 이전 한국어 1.4 설계 기록. 현재 공통 본문의 원본이 아니다.

## 실제 확인한 범위

- 113,400개 설정 조합: 결정성, 모드 정규화, 필수 필드와 치환 검사.
- 252개 장르×테마: 공통 섹션, T1–T6, R01–R17 포함, 선택 계약 일치, 실제 HTML 내 조립기와 원본 출력 일치.
- 음소거·움직임 설정·재도전·세부 행동·한국어 입력·특수문자·치환 구문처럼 보이는 입력 보존.
- 필수 섹션 제거, 중복/미정의 치환, 누락된 영문 계약을 실패로 검출.
- 실제 배포 `index.html`의 브라우저 실행: 선택 반영, 복사 성공/거부 대체, 미리보기·TXT 일치, 대화상자 복귀, 320px 포함 6개 화면 폭, 확대 상당 화면, 오프라인, 외부 요청 0, 실행 오류 0.
- 기존 입력 참조 모듈: 단위 검사 16개와 임의 이벤트 10,000판 통과. 이는 프롬프트로 생성될 게임의 상태 구현을 대신 검증한 것이 아니다.

상세 결과는 `docs/verification/compiler.json`, `prompt-contract.json`, `design-browser.json`, `input-unit.json`에 있다. 현재 예시 프롬프트는 약 39,000자이며 문자 수를 토큰 수로 환산하거나 영어로 바꿨다는 이유로 생성 정확도 향상을 단정하지 않는다.

## 남아 있는 외부 검증

실제 ChatGPT 첫 출력 게임의 장르별 제작·실행, 제공되지 않은 오류 HTML의 재현, 실제 전자칠판 6인 동시 터치는 이번 생성기 검사에 포함되지 않는다. 프롬프트는 이를 제작 모델에 요구하지만 실행 권한/도구가 없는 모델이 실행했다고 보고하지 않도록 명시했다. 한 번의 프롬프트로 모든 자료·환경에서 완벽하게 생성된다는 보장은 하지 않는다.
