# 수학 공작소: 테마별 시각 명세

`prototypes/art-direction.js`에서 12개 테마의 장면, 원경/중경/전경 색, 주요 오브젝트, 재질, 정답 반응을 관리한다. 미리보기와 출력 프롬프트가 이 데이터를 공유하며 빌드 때 테마별 `visualContract`를 조립한다. 이전의 장식 위주 SVG 렌더러는 제거했다.

디자인 지시는 화면 구역, 레이어 순서, 주요 오브젝트의 면과 그림자, 문제판의 여백과 불투명 배경, 버튼 두께, 대비, 장르와 테마를 함께 적용하는 방법을 포함한다. 미리보기는 구성 예시이며 선택형 숫자 문제를 모든 장르에 강제하지 않는다. 외부 이미지 생성 서비스나 별도 파일 첨부는 요구하지 않는다.

브라우저 18항목에서 12개 테마의 미리보기 설명과 복사 프롬프트의 디자인 계약 연결, 6개 화면 폭, 복사·저장·오프라인을 확인했다. 113,400개 조립 조합과 기존 색상 대비 44쌍도 통과했다. 대비 검사는 지정된 본문/패널 색상쌍의 범위이며 전체 그림을 자동 인증하는 검사가 아니다. 생성된 게임의 실제 디자인 품질은 이 조립 검사와 구분한다.

추가 요청에 따라 머리말의 찰떡쌤 표기를 제거하고 하단 저작권은 유지했다.
