# 수학 공작소 프롬프트 1.3 변경 기록

## 발견한 문제

효과음은 내부 기본값이 꺼져 있고 UI에서 변경할 수 없었다. 기존 시각 반응 요구는 포괄적인 문장에 그쳐 사건 연결·동시 실행·정리가 불명확했다. 문제 생성 조건은 있었지만 저장된 정답과 독립적인 풀이 검산, 유형 변형의 선정 절차가 구체적이지 않았다.

## 변경

- 정답·오답·단계·종료별 시각 반응과 Web Audio 효과음, 동시 음원·입자 제한, 일시정지와 정리 규칙을 공통 프롬프트에 추가했다. 생성기에서 효과음·움직임 설정을 노출한다. 이 설정은 생성할 게임에 전달하며 생성기 자체에서 소리를 재생하지 않는다.
- 학생 화면에 남길 정보와 교사 메뉴로 옮길 정보를 구체적으로 정했다. 문제 조건·단위는 줄이지 않고 중복 지표·상시 설명을 줄인다.
- 자료별 가족·변형·난도 데이터, 원시 조건에 의한 독립 검산, 보기 동치 검사, 출제 묶음과 최근 중복 기록, 문제 점검의 표본·경계 사례를 명시했다.

## 검증 범위

조립 113,400조합·예외 6그룹, 브라우저 17항목·6화면 폭을 통과했다. 효과음 켬/끔과 움직임 기본/줄이기/기기 설정이 복사 프롬프트에 반영되고, 무음 선택에도 효과음 구현 요구가 남는 것을 확인했다. 기본 조합 출력은 11,461~11,807자이며 글자 수를 토큰 수로 해석하지 않는다. 이 검증은 생성기와 프롬프트 조립에 대한 것이며 ChatGPT가 생성할 게임의 수학·시청각 품질을 실제 실행해 인증하는 시험은 아니다.
