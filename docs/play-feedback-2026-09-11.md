# 플레이 피드백 반영 · 2026-09-11

- 생성기 UI: 게임 아이콘·유형 설명 카드, 명확한 선택 상태, 수업 조건 패널과 난이도 보조 문구. 효과음/움직임 입력 제거. 효과음 켬·움직임 시스템 설정으로 출력.
- 프롬프트: 기본 오답 처리는 오답 확정 → 감점 및 1.2초 개인 잠금 → 정답/풀이 → 다음 문제. 정답 +10점, 오답 −5점(최저 0). 점수 없는 장르는 개인 잠금과 시도 보상 0. 협동은 타인에게 감점하지 않음.
- 공통 문제의 해설은 모두 제출 또는 라운드 마감 후 공개. 재도전은 최초 오답 기록 유지 및 보상 0. 탐색·취소와 답 제출 구분.
- 디자인: 장면 깊이, 대비, 버튼 상태, 정답마다 장르 대상 변화, 단계 달성 효과 명시.
- 배포: 단독 실행 가능한 루트 index.html을 빌드 결과로 추가. 연결 저장소 없음·로컬 GitHub 인증 만료로 실제 배포는 미실행. 별도 안내 제공.

검증: 113,400개 프롬프트 조합, 브라우저 선택/검색/복사 대체/다운로드, 320~1440px 여섯 화면 크기, 오프라인 외부 요청 0, 브라우저 오류 0. 화면 캡처를 시각 검토함.
