# 실제 활동지 분석과 게임화 설계

분석일: 2026-09-10. 대상: `sample/worksheet`의 PDF 6개, 총 16쪽, 번호가 붙은 본문 문항 102개. 소문항은 별도로 세지 않았다. 전 페이지를 이미지로 렌더링해 텍스트와 함께 확인했다. 원본 PDF는 수정하지 않았다.

이 문서는 자료 분석, 게임화 설계, 대표 수학 규칙 검토 결과다. 102문항의 공식 정답표 검증이나 무료 ChatGPT·완성 게임·실제 전자칠판 시험 결과는 아니다.

## 2. 읽을 때 발견한 구조 문제

### 텍스트만 읽으면 수학이 달라지는 자료

- D의 `3/9 × 2/4`가 추출 텍스트에서는 `39 X 24`처럼 붙었다. 첫 문항의 파란 `1/6`은 예시 답으로 따로 보였다.
- T셀파·아이스크림 PDF의 일부 숫자와 분수는 사용자 정의 글꼴 문자로 추출됐다. 눈에 보이는 분자·분모와 추출 순서가 다를 수 있다.
- B 6번의 빈 원·채운 원, F 2번의 경계점과 방향은 글로만 추출되지 않는다.
- L 12번, H 2·13번의 수 카드와 I 4·9·11·15·19번의 연결·배열·분할·화살표에는 그림 안의 필수 정보가 있다.
- `[9~10]`, `[18~19]`, `[7~8]` 같은 공통 조건을 문항과 함께 읽어야 한다.

따라서 ‘추출 문자열이 있으면 판독 성공’으로 처리하지 않는다. 분수·그림·수직선·표가 채점에 필요하면 이미지로 확인하고, 필요한 부분을 확인할 수 없을 때만 해당 부분을 질문한다. 선명한 자료까지 매번 재첨부시키지 않는다.

### 제작 과정의 출처·범위 처리

범위는 파일명 + PDF 쪽 + 문항 번호로 추적한다. 정답·풀이가 포함된 페이지가 추가되면 출제 본문과 구분한다. 여러 단원이 있고 교사가 범위를 지정하지 않았다면 단원 선택이 필요한 경우 한 번 질문한다. 같은 단원 안의 다양한 형식은 이를 이유로 자동 질문하지 말고 학습 목표에 따라 정리한다.

학년 선택은 ‘지정 안 함(자료 수준 유지)’을 추천 기본값으로 한다. 표기가 없으면 문제의 개념을 추론하되 정확한 학년·차시를 꾸며 쓰지 않는다. 교사가 명시한 학년이 자료와 다르면 자료의 실제 개념을 우선 확인한다. UI 기본값을 사용자 의도로 오해해 문제를 임의 변환하지 않는다.

## 5. 실제로 작동하는 무작위 출제를 위한 계약

### A. 수의 범위

기준값 t와 관계(이상·이하·초과·미만), 검사값 x를 분리한다. 소수는 정수 배율로 저장한다. 문항 묶음에는 `t보다 작음 / t와 같음 / t보다 큼`을 고르게 넣어 경계값 이해를 실제로 확인한다. 수직선의 빈 원·채운 원과 판정 함수는 같은 관계 값에서 생성한다.

복수 선택은 정답 ID 집합 전체를 판정한다. ‘모두 고르기’를 단일 정답이라고 가정하지 않는다. 카드별 분류로 바꿀 때는 각 카드의 판단이 기록되고, 전체 묶음의 오분류를 확인할 수 있어야 한다.

### B. 올림·버림·반올림과 개수

입력값과 목표 자리 간격을 분리한다. 5에서 올리는 비음수 반올림 규칙을 정확한 정수/유리수로 처리한다. 정확한 경계와 경계 바로 양쪽을 시험한다. ‘몇 명/몇 장’은 정수 단위이며 연속량의 소수 정답으로 처리하지 않는다.

주차 문제 B 20번 원문은 추가 시간이 10분 단위로 정확히 나누어진다. 숫자만 바꿔 95분 같은 값을 만들려면 ‘10분 미만도 10분으로 계산’ 등의 정책을 명시해야 한다. 원자료에 없는 요금 규칙을 추측하지 않는다. 첫 템플릿은 추가 시간을 과금 단위의 정수배로 생성한다.

### C. 진분수 곱셈·약분

양의 정수 분모 b·d와 `0<a<b`, `0<c<d`인 분자에서 시작한다. 곱의 값은 `(a*c)/(b*d)`이며 최대공약수로 정규화한다. 입력 분수가 기약분수여야 한다는 추가 제약은 원자료에 없으므로 임의 강제하지 않는다.

PRD 2.0의 주관식 금지에 맞춰 학생은 기약분수 보기 또는 약분 경로 카드를 선택한다. 숫자·분수 키패드는 사용하지 않는다. 판정은 다음을 분리한다.

- 분모 0: 문항/보기 생성 오류로 제외하며 1로 자동 대체하지 않음.
- 선택한 보기의 값이 다름: 계산 또는 보기 판단 오류.
- 값은 같지만 기약분수 조건 불충족: ‘같은 값이지만 더 줄일 수 있어요’처럼 형식과 값의 차이를 설명.
- 값과 요구 형식 모두 맞음: 최종 득점. 약분 경로 잇기에서는 유효한 모든 경로 인정.

객관식 보기의 유일성은 표시 문자열이 아니라 약분한 값으로 검사한다. `1/2`, `2/4`, `0.5`가 동시에 답 보기에 있으면 동일 값이다. 관계 연결처럼 복수 대응을 허용하는 게임은 유효한 관계 전체를 판정한다.

### D. 사용·남음·부분의 부분

‘현재 전체’를 단계마다 추적한다. 예를 들어 `N에서 a/b 사용 → 남은 것의 c/d 사용 → 최종 남은 양`은 `N(1-a/b)(1-c/d)`다. 사용한 양, 두 번째 사용량, 최종 남은 양을 각각 별도 목표로 정의한다.

사람·사탕처럼 낱개 대상은 각 중간 단계도 정수여야 한다. 단순하고 안전한 구성법은 `N=b*d*k`를 먼저 정하는 것이다. 길이·무게처럼 나눌 수 있는 양은 허용한 유리수와 단위를 사용한다. 사람 2.4명처럼 문맥에 맞지 않는 문제를 거부한다.

### E. 역추론·카드 극값·부등식

역추론은 성립하는 숨은 전체/정답을 먼저 정하고 관측값을 만든다. 카드 문제는 가능한 배치를 전수 열거해 최댓값·최솟값을 검증한다. 값이 같은 여러 최적 배치 또는 곱셈 순서 교환을 오답 처리하지 않는다.

양의 수 q보다 작은 자연수의 개수는 `max(0, ceil(q)-1)`, q보다 큰 가장 작은 자연수는 `floor(q)+1`이다. 자연수는 이 자료의 맥락에서 1부터로 정의한다. 특히 q가 정수일 때 엄격 부등식의 경계를 별도로 시험한다.

### F. 그림·절차형 문제

데이터에서 그림·정답·해설을 함께 생성한다. 분할 수가 많아 6인 조작이 작아지면 자료 범위 안에서 분모 범위를 조절하거나 하단 조작의 단계를 나눈다. 상단은 큰 관람 그림만 두고 조작을 옮기지 않는다. 보기와 실제 클릭 영역이 일치해야 한다. 다단계 문제는 주어진 보기·조각의 단계별 선택으로 다루며 한 학생의 중간 단계 때문에 다른 학생이 대기하지 않게 한다.

## 6. 난이도와 장르를 결정하는 방법

같은 개념 안에서 수의 크기·분모·교차 약분·선택지 유사도·시각적 도움·단계 수를 조절한다. D의 ‘상’에 대분수나 분수 나눗셈을 자동 도입하지 않는다. F의 ‘상’에도 자료 범위 밖 초과·미만을 자동 추가하지 않는다.

H의 역추론을 ‘하’로 낮출 때는 어려운 관계를 삭제하기보다 숫자를 단순화하고 단계별 그림·선택 도움을 먼저 준다. 원래 개념을 다른 쉬운 개념으로 교체하는 것은 난이도 조절과 구분한다.

| 자료 특성 | 먼저 추천할 장르 | 변환 시 주의 |
|---|---|---|
| 짧은 연산·기약분수 | 퀴즈 배틀·레이싱·단순 타깃 슈팅 | 하단 분수 보기·약분 경로 선택, 동치와 표현 형식 구별 |
| 경계 포함·범위 판정 | 분류 공장·조건 미로·영토 점령 | 빈 원·채운 원, 모두/아닌 것 유지 |
| 식·답의 동치 | 관계 잇기·기억 카드 | 같은 값 여러 카드의 관계 처리 |
| 분수 원리·도형 | 도형·분수 조립 | 실제 같은 크기 분할을 조작하게 함 |
| 카드 극값·연산 순서 | 순서 퍼즐·단서 탐정 | 최적 배치가 여러 개일 수 있음 |
| 돈·포장·정수 묶음 | 수학 상점·자원형 디펜스 | 올림/버림의 상황 의미 유지 |
| 남은 양·다단계 역추론 | 단계별 협동 보스전·단서 탐정 | 단계를 게임 진행으로 표현, 읽기 시간을 확보 |

20개는 장르 카탈로그이고 수학 엔진 종류와 같지 않다. 모든 자료를 모든 장르에 억지로 맞추지 않는다. 특히 규칙 작곡(이전 이름 패턴 리듬)을 분수 계산에 단순히 얹거나, 숫자 합성의 2배 규칙 때문에 분수 곱셈 목표를 바꾸면 학습 목표가 손상될 수 있다. 장르명보다 핵심 수학 행동의 적합성을 우선한다.

## 7. 첫 실험용 세 가지 설계

### 1) 경계 통과 분류 공장

자료: F 전체. 처음에는 이상·이하만 사용한다. 개인 하단 조작대에 숫자 카드와 큰 ‘포함/제외’ 버튼을 두고, 자신이 분류한 카드가 공통 공장 목표에 기여한다. 1~6명 동시 조작, 인원·시간·수학 난이도 조절. 경계값과 단순 소수 판정이 확인 대상이다.

### 2) 분수 약분 레이싱

자료: D 전체. 진분수 두 개의 곱을 기약분수 보기에서 고르거나 주어진 약분 경로 카드를 잇는다. 유효한 경로 판단이 경주의 이동·갈림길 선택과 연결되어야 한다. 자유 답안은 쓰지 않는다. 동치인 약분 전 보기는 수치 오류와 구분해 피드백한다. 최종 보상은 한 번만 적용하며 분수 보기의 중복·재시작·6인 하단 조작판을 검증한다.

### 3) 남은 자원으로 협동 보스전

자료: H 14번과 필요할 때 L 5번. 각 학생은 ‘사용량/남은 양/남은 것의 일부’를 단계별로 구해 방어·공격 자원을 만든다. 기준량이 바뀌는 모습을 막대로 표시한다. 한 학생의 긴 풀이가 다른 학생의 진행을 막지 않는다. 단순 답 맞히기 보상만 붙이지 않고 자원 변화 자체가 수학 관계를 보여줘야 한다.

시작 실험은 서로 다른 실패 유형을 겨냥한다. 분류 공장은 경계·집합, 레이싱은 유리수·형식 판정, 보스전은 문장 의미·중첩 기준량이다. 이 결과가 나오기 전에 전체 20개 장르의 완성도를 보장하지 않는다.
